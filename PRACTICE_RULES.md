# Practice Rules

For every topic:

1. Write the logical structure and physical representation.
2. State invariants.
3. Design the API.
4. Implement without STL shortcuts.
5. Add boundary tests.
6. Record time/space complexity.
7. Review memory ownership and failure cases.

Recommended order: linear lists -> stack/queue -> strings -> trees -> heaps -> graphs -> disjoint sets -> sorting -> searching -> indexes -> algorithm design.
